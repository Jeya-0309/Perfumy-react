# 🌸 Perfumy – React Learning Project

A simple perfume shopping website built using **React.js** as part of my React learning journey.

This project helped me understand React fundamentals, component-based architecture, JSX, importing and exporting components, and rendering UI using React.

## 🚀 Live Demo

[View Perfumy Website](https://perfumy-react-liard-ten.vercel.app/)

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6)
- HTML5
- CSS3
- JSX

## ✨ Features

- Navigation bar with Home, Products, About and Contact sections.
- Search bar for product search UI.
- Products section displaying perfume images and descriptions.
- About Us section.
- Footer with contact information.

## 📚 React Concepts Learned

Through this project, I practised:

1. **Functional Components** – Creating reusable components using JavaScript functions.
2. **JSX** – Writing HTML-like syntax inside JavaScript.
3. **Component Import & Export** – Separating UI into multiple files and importing them into App.js.
4. **className** – Using className instead of class in JSX.
5. **Inline Styling** – Applying CSS styles using JavaScript objects.
6. **Image Importing** – Importing images from the assets folder.
7. **ReactDOM** – Rendering the App component using createRoot().

## ⚙️ Installation and Setup

Clone the repository:

```bash
git clone [GITHUB_REPOSITORY_URL](https://github.com/Jeya-0309/Perfumy-react.git)
```

Navigate to the project folder:

```bash
cd perfumy-react
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```
